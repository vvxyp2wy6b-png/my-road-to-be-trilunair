# My Road to be Trilunair Dr.MaJoOoOoOoD
## مركز القيادة المالي الهولوغرامي ونظام الأوامر الصوتية بالذكاء الاصطناعي
### Premium Holographic UI & Voice-First AI Command System

منصة قيادة وتداول هولوغرامية متكاملة مصممة خصيصاً لمشروع **My Road to be Trilunair Dr.MaJoOoOoOoD**، تجمع بين التصميم الزجاجي الفضائي المتقدم (Advanced Glassmorphism)، ومحرك سمات ديناميكي مستديم بخمس سمات قياسية، وغرفة أوامر صوتية ونصية باللغتين العربية والإنجليزية، وقاعة اجتماع وكلاء الذكاء الاصطناعي المدمجة مباشرة في قاعة التداول الحية، مع بوابة أمان وتصاريح حتمية تجعل **التداول الورقي (Paper Trading)** هو الوضع الافتراضي دائماً.

---

## المزايا المعمارية الأساسية (Core Capabilities)

### 1. التصميم الهولوغرامي الفاخر والطباعة العربية المتكاملة (Visual Design & RTL)
- ألواح زجاجية متعددة الطبقات (Glassmorphism) مع حدود هولوغرامية وإضاءة نيون دقيقة قابلة للضبط.
- دعم كامل للغة العربية واتجاه `RTL` افتراضياً مع إمكانية التبديل الفوري إلى الإنجليزية `LTR`.
- خطوط احترافية عالية المقروئية (`Cairo` + `IBM Plex Sans Arabic` للنصوص، و `IBM Plex Mono` بالأرقام الجدولية `tabular-nums` لضمان وضوح الأسعار والطلبات ومؤشرات المخاطر تحت جميع الظروف).
- عناصر بصرية تفاعلية ثنائية وثلاثية الأبعاد:
  - **مخطط الشموع الهولوغرامي وعمق السوق (2D Interactive Candlestick & Orderbook Depth)**.
  - **مجسم الثروة الهولوغرامي ثلاثي الأبعاد (3D Interactive Portfolio Topology Orb)** قابل للتدوير بالماوس واللمس، ومحمّي بحدود عزل الأخطاء (`VisualEffectsBoundary`) بحيث تستمر عمليات التداول بكفاءة 100% حتى لو تعطلت المؤثرات الرسومية.

### 2. محرك السمات الديناميكي المستديم (Dynamic Theme Engine)
يعتمد بالكامل على متغيرات التصميم القياسية (CSS Custom Properties) دون أي ألوان ثابتة داخل المكونات، ويشمل السمات الخمس الأساسية:
1. **Royal Gold** (الملكي الذهبي)
2. **Quantum Cyan** (السيان الكمي)
3. **Nebula Purple** (سديم الأرجوان)
4. **Emerald Matrix** (المصفوفة الزمردية)
5. **Arctic Platinum** (البلاتين القطبي)

- تخصيص فوري لألوان التمييز والخلفيات، وشدة التوهج، والضبابية، والشفافية، وشدة الحركة.
- حفظ السمات المخصصة واستدامتها في `LocalStorage` وقاعدة بيانات `SQLite` على الخادم.
- تصدير واستيراد ملفات السمات بصيغة `JSON` مع التحقق الهيكلي.
- أوضاع الوصولية والأداء: **تعطيل الحركة**، **وضع التباين العالي (High-Contrast Mode)**، و**وضع الطاقة المنخفضة (Low-Power Rendering Mode)**.

### 3. غرفة الأوامر الصوتية بالذكاء الاصطناعي (Voice-First AI Command Dock)
- شريط قيادة مستديم ومتاح عبر كافة الشاشات الرئيسية.
- التعرف على الكلام بالعربية (`ar-SA`) والإنجليزية (`en-US`)، والمحادثة النصية المستقلة تماماً عن صلاحيات الميكروفون.
- وضع **اضغط للتحدث (Push-to-Talk)** ووضع **المحادثة الحرة (Hands-Free)** مع مؤشر حالة ميكروفون صريح.
- خصوصية صارمة: لا يبدأ أي تسجيل صوتي دون إذن صريح من المستخدم، مع زر فوري لإلغاء التصريح أو **مقاطعة النطق الصوتي (Interruptible TTS)** في أي لحظة.
- تخضع الأوامر الصوتية والنصية لنفس خط أنابيب التحقق الهيكلي وفحص المخاطر الحتمي وبوابة التصاريح المعمول به في تذكرة التداول المباشرة دون أي استثناء.

### 4. قاعة اجتماع الوكلاء في قاعة التداول الحية (Agent Meeting Room)
مدمجة مباشرة داخل شاشة **قاعة التداول الحية (Live Terminal)** وتضم:
- **د. ريان (المحلل الكمي — Quant Alpha)**
- **سارة (حارسة المخاطر — Risk Sentinel)**
- **طارق (استراتيجي الاقتصاد الكلي والسيولة — Macro & Liquidity)**
- **خالد (مهندس التنفيذ وتكاليف التداول — Execution Architect)**
- **المجلس التنفيذي (التوصية النهائية المجمعة — Chief Strategist)**
- تعرض حالات الوكلاء، نقاط الاتفاق والاختلاف، الأدلة الداعمة وعوامل عدم اليقين، التكاليف التقديرية للصفقة، التقييم الحتمي للمخاطر، مع إمكانية الاستماع إلى الجلسة الحوارية منطوقةً بالصوت العربي أو الإنجليزي.

## التشغيل السريع (Quick Start)

### التشغيل المحلي للتطوير
```bash
# 1. تشغيل الخادم الخلفي (FastAPI + WebSocket + SQLite) على المنفذ 8000
cd backend
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000

# 2. تشغيل الواجهة الأمامية (Vite + React + TypeScript) على المنفذ 5173
cd ../frontend
npm run dev
```
أو عبر سكربت التشغيل الموحد:
```bash
./start.sh
```

### التشغيل عبر Docker Compose
```bash
cp .env.example .env
docker compose up --build -d
```

### تشغيل الاختبارات الآلية الشاملة
```bash
# اختبارات الأمان ومحرك المخاطر وبوابة التصاريح والوكلاء في الخادم الخلفي
cd backend && uv run pytest -v

# اختبارات الواجهة ومحرك السمات وغرفة الأوامر الصوتية والوصولية
cd ../frontend && npm test
```
